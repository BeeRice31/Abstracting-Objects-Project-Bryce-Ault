This project is modeled after a cargo Train and contains three classes: Train, Cargo, and TrainTester. 
These classes mimic a cargo train's behavior in the real world, including fuel level, cargo, movement, and destination.
The Train class is responsible for the actions that a train can take
The Cargo class is responsible for how cargo interacts with trains
The TrainTester class is responsible for running the methods and making the train
